## 📑 Estructura del Curso
El programa formativo está dividido en tres módulos progresivos que integran el uso de Inteligencia Artificial como asistente de aprendizaje:

### **Módulo 1: Excel Intermedio (25 horas)**
En este bloque asentaremos las bases para profesionalizar el uso de hojas de cálculo.
*   **Gestión de Entornos:** Uso avanzado de nombres de rangos y referencias.
*   **Formatos Profesionales:** Formatos personalizados y condicionales mediante fórmulas.
*   **Lógica y Texto:** Funciones SI, SI.CONJUNTO y limpieza de datos desordenados.
*   **Análisis Inicial:** Introducción a tablas dinámicas y herramientas de simulación como Búsqueda de objetivos y Solver.

### **Módulo 2: Excel Avanzado + IA Aplicada (75 horas)**
El núcleo del curso, enfocado en el análisis complejo y la automatización.
*   **Dashboards en Excel:** Gráficos dinámicos, segmentadores de datos y cuadros de mando ejecutivos.
*   **Funciones Modernas:** BUSCARX y funciones de matriz dinámica (FILTRAR, UNICO, ORDENAR).
*   **Automatización y ETL:** Introducción a Power Query para limpieza masiva de datos y creación de formularios.
*   **Macros y VBA:** Creación de automatizaciones y edición de código asistida por IA (ChatGPT/Claude).

### **Módulo 3: Power BI + AI Insights (50 horas)**
Transformación de datos en inteligencia de negocio visual e interactiva.
*   **Modelado de Datos:** Conexión a fuentes, procesos ETL avanzados y diseño de esquemas en estrella.
*   **Lenguaje DAX:** Creación de medidas y cálculos de inteligencia de tiempo.
*   **Visualización Avanzada:** Objetos visuales de IA, narrativas inteligentes y uso de Microsoft Copilot.
*   **Publicación:** Gestión de informes en Power BI Service y colaboración en la nube.

## 🛠️ Cómo utilizar este repositorio
1.  **Teoría:** Encontrarás los manuales diarios en formato `.md` o `.pdf` dentro de las carpetas de cada sesión.
2.  **Ejercicios:** Los archivos de Excel iniciales para las prácticas están numerados según el día correspondiente (ej. `Dia_01_Ejercicios.xlsx`).
3.  **Datos:** Los datasets externos (CSV, archivos financieros) se encuentran en la carpeta `/Data`.
